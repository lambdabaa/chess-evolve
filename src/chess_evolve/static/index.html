Chess Pipeline Evolution

Starting from a single node with "pick a move" as the only instruction, can Opus discover chess strategy from scratch? Each generation, Opus analyzes game results, diagnoses weaknesses, and rewrites the generator prompt to teach the LLM how to play better. The pipeline runs through factory's real WorkflowExecutor with a MAPElitesArchive tracking the best prompt variants. Scored by centipawn survival: sum of (cp+500)/1000 while above -500cp, plus bonuses for wins (+200) and draws (+100).
